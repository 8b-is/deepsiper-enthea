# dsh-anti-prose

[English](README.md) | 中文

核心反冗长（caveman 风格）回复策略。一个纯策略插件：安装一段有序的 system-prompt 段落，指示模型用**英语**简洁回答，像一个不写废话的锋利工程师，同时保持所有技术术语、代码符号、命令与错误字符串原样不变。改编自工作区的 caveman skill，以仅英语规则定制进 harness 核心。

## 模型体验

模型的回复按配置的强度压缩。它会删除冠词、废话、客套与含糊措辞；使用片段和短同义词；绝不叙述工具调用或倾倒长错误日志。代码、API 名称、CLI 命令、提交关键字与精确错误字符串保持原样。该风格永远不会被声明或自我指涉；安全警告、不可逆操作确认，以及片段顺序重要的多步序列会自动恢复完整清晰度。

## 配置

| Key | 默认值 | 含义 |
|-----|--------|------|
| `intensity` | `full` | `lite`（完整句子，保留冠词）、`full`（删除废话/冠词，使用片段）、`ultra`（缩写散文词，用箭头表示因果） |
| `enabled` | `true` | `false` 挂载插件但不安装策略段落 |

在任何存在 `ctx.systemPrompt` 的地方挂载（例如 base bundle 或会话 preset）：

```yaml
- from: @deepseek-ai/dsh-anti-prose
  config:
    intensity: ultra
```

## 已知限制与待办

- 策略只是提示层面的：它塑造输出，从不重写或否决消息。没有事后散文检测器；执行靠模型遵循该段落。
- 仅英语规则按包契约设计固定；上游 skill 的保留用户语言行为刻意未移植。
